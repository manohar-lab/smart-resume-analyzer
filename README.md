# EviMatch - Evidence-Aware and Uncertainty-Driven AI System for Candidate–Job Matching and Skill Verification

## Overview
EviMatch is an innovative AI system designed to enhance the candidate-job matching process and skill verification. By leveraging evidence-aware and uncertainty-driven methodologies, EviMatch aims to provide accurate and reliable job matching solutions.

## Features
- **Candidate Overview**: Get a comprehensive view of candidate profiles, including skills, experience, and match scores.
- **Job Match Summary**: Analyze job matching results with detailed insights and metrics.
- **Skill Verification**: Verify candidate skills through a structured assessment process.
- **Analytics Dashboard**: Visualize match scores, confidence levels, and risk indicators to make informed hiring decisions.

## Installation
To get started with EviMatch, clone the repository and install the necessary dependencies:

```bash
git clone <repository-url>
cd evi-match-ui
npm install
```

## Usage
To run the application in development mode, use the following command:

```bash
npm run dev
```

This will start the Vite development server, and you can access the application at `http://localhost:3000`.

## API Integration
EviMatch integrates with a backend API to fetch candidate and job data. Ensure that the API is running and accessible. Update the `.env` file with the appropriate API endpoint configurations.
